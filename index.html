Research

In progress Independent project · 2026

Type I interferon in tuberculosis and cutaneous leishmaniasis

Two very different infections share one host cell: the macrophage. This project asks which parts of the type I interferon response in blood are common to tuberculosis and cutaneous leishmaniasis, which are specific to each disease, and whether that response follows the outcome of treatment.

The first phase reanalyses public tuberculosis cohorts. Every cohort is scored on its own, and every finding is re-tested in independent studies before it counts.

  1. 1 Public cohorts RNA-seq and microarray data from NCBI GEO
  2. 2 Gene-set scores z-scores within each cohort, never pooled across studies
  3. 3 Diagnostic performance ROC curves with bootstrap confidence intervals
  4. 4 Independent validation Each result checked again in separate cohorts
  • Python
  • R
  • pandas
  • scikit-learn
  • ggplot2
  • pROC
  • MSigDB

Reproducible in both Python and R. The repository is private for now, until the results are published.
